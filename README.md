# Filament Users Permissions & Roles

## English

Complete user, role and permission management for Filament 5 with Spatie Laravel Permission.

### Features

- 🎯 **Full integration** with Spatie Laravel Permission
- 🚀 **Filament 5** compatible
- 👥 **Role management** with permission assignment
- 🔑 **Permission management** with grouping
- 👤 **User role/permission** assignment interface
- 🛡️ **Protected roles** (cannot be deleted)
- 📊 **Statistics widget**
- 🌐 **Multi-language** support
- ⚡ **Caching** for performance
- 🔄 **Bulk actions** for management

### Installation

```bash
composer require kushelbek/filament-users-permissions-roles
